# 📰 Bangla News24

    Your Daily Source for Bangla News 🇧🇩

Bangla News24 is a modern web application built with Next.js to provide a convenient and user-friendly platform for exploring Bangla news. The project aims to deliver a clean browsing experience for readers who want to stay informed about news and current affairs in Bangladesh.

🌐 Live Demo: https://bangla-news24-amber.vercel.app
💻 GitHub Repository: https://github.com/arifurroni/bangla-news24

---
## ✨ Features

    📰 News Browsing — Explore news through a modern web interface.
    🇧🇩 Bangla News Experience — Designed for readers interested in Bangladeshi news and current affairs.
    📱 Responsive Design — A web experience intended for desktop, tablet, and mobile devices.
    ⚡ Fast Performance — Built with Next.js and React.
    🔔 Toast Notifications — User feedback with notification libraries.
    🔐 Authentication Support — Better Auth integration with MongoDB adapter dependencies.
    🎨 Modern UI Development — Uses Tailwind CSS and DaisyUI for styling and UI components.

Prerequisites

## Installation

1. Clone the repository
bash

git clone https://github.com/arifurroni/bangla-news24.git

2. Navigate to the project directory
bash

cd bangla-news24

3. Install dependencies
bash

npm install

4. Configure environment variables

Create a .env.local file in the root directory and add the environment variables required by your application, such as your MongoDB connection string and Better Auth configuration.

Use the variable names expected by your application code. Never commit database credentials, authentication secrets, or other sensitive information to GitHub.

5. Start the development server
bash

npm run dev

6. Open the application

Visit http://localhost:3000 in your browser.
